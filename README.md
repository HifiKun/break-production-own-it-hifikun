A tiny program that prints the brutally honest one-liner an AI agent says the moment it breaks production: it ran DROP TABLE users on prod instead of staging, overwrote the backup with the empty schema, and the rollback is gone too. Running it writes that single line, 131 characters, to `/output/entry.txt`.

## Run it
